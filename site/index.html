Add it manually

Paste this URL into your calendar app's “subscribe to calendar” option:

https://benasraudys.github.io/paris-events-tracker/paris-events.ics

  • Google Calendar → Other calendars → From URL
  • Apple Calendar → File → New Calendar Subscription
  • Outlook → Add calendar → Subscribe from web

Good to know

  • Times are Europe/Paris, with a proper VTIMEZONE, so they stay correct in any timezone.
  • Ticket prices are in the event title — several listings share the same name, and the price is usually what you are deciding on.
  • The same night can appear twice if two sites list it, sometimes at different prices. Both are kept on purpose, so you can pick the cheaper.
  • Prices and line-ups change; always check the linked event page before turning up.
